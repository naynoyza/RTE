# Tracker — กล้อง + YOLO + MediaPipe -> Unity

อ่านภาพจากกล้อง Orbbec แล้วแบ่งงาน 2 ส่วน ส่งข้อมูลให้ Unity ทาง UDP

| ส่วน | ทำอะไร | ไฟล์ |
|---|---|---|
| **YOLO** (การ์ดจอ, thread แยก) | หา**กรอบ/ตำแหน่งคน**ทุกคน + ให้ id ต่อเนื่อง -> ล็อค P1/P2 (ไม่ใช้จุดกระดูกของ YOLO) | `yolo_detect.py`, `player_lock.py` |
| **MediaPipe Pose** (CPU) | ตัดภาพเฉพาะกรอบของผู้เล่นแต่ละคน -> **โครงกระดูก** 33 จุด แปลงเป็น 17 จุดแบบเดิม (Unity ไม่ต้องแก้) | `skeleton_mp.py` |

ระยะ (2–3 ม.), การนับย่ำเท้า และตำแหน่งมือ คำนวณจากโครงกระดูก MediaPipe ด้วยสูตรเดิมใน `gestures.py`

## ติดตั้ง (ครั้งเดียว)
```
setup_venv.bat        (ดับเบิลคลิก: สร้าง venv + pip install -r requirements.txt + โหลดโมเดล MediaPipe)
```
* ต้องใช้ **Python 3.11** และต่อเน็ตตอนรัน `setup_venv.bat` ครั้งแรก (หลังจากนั้นเล่นแบบไม่มีเน็ตได้)
* โมเดล `models/yolov8n-pose.onnx` มีให้แล้ว (Git LFS) รันบนการ์ดจอผ่าน DirectML (เลือกตัวที่เร็วที่สุดเอง)
* MediaPipe ใช้โมเดล lite เป็นค่าเริ่มต้น (เร็ว) — เครื่องแรงอยากได้ความแม่นขึ้น: `run_tracker.bat --mp-complexity 1`

## รัน
1. ดับเบิลคลิก `run_tracker.bat` จะมีหน้าต่างพรีวิวกล้อง
2. Unity: เปิดฉาก `Assets/Scenes/WasteHunters.unity` แล้วกด Play

| ปุ่มในหน้าต่างพรีวิว | ทำอะไร |
|---|---|
| Q / Esc | ปิดโปรแกรม |
| D | คาลิเบรตระยะ: ยืนห่างกล้อง 1 เมตรพอดี แล้วกด (ทำครั้งเดียว) |
| C | คาลิเบรตมือ 6 วินาที: ผู้เล่นกวาดมือที่ยกไปทุกมุม |
| R | ปลดล็อคผู้เล่นทั้งสอง |

## กติกาการจับคน
* **เข้าเล่นได้เฉพาะระยะ 2–3 เมตร** (`--min-m 2.0 --join-m 3.0`) ใกล้หรือไกลกว่านี้ไม่รับ
* ยืนฝั่งซ้ายของกล้อง = P1, ฝั่งขวา = P2
* ล็อคแล้วตามคนนั้นจนกว่าจะ **ออกจากกล้อง** เดินใกล้/ไกลแค่ไหนก็ไม่หลุด คนอื่นในกล้องไม่ถูกนับ
* ถ้า YOLO หาตัวไม่เจอชั่วครู่ ยังเก็บช่องไว้ `--lost-grace` (1.5 วินาที)
* หน้าต่างพรีวิววาดโครงกระดูก (MediaPipe) เฉพาะ P1 (ฟ้า) / P2 (ส้ม)
* ระยะของคนที่ยังไม่เป็นผู้เล่นวัดเฉพาะตอนที่ยังมีช่องว่าง (MediaPipe ทีละคนต่อเฟรม) ครบ 2 คนแล้วไม่วัดคนอื่น

## ข้อมูลที่ส่งให้ Unity (ต่อผู้เล่น)
`present` ล็อคอยู่ไหม • `dist` ระยะ (ม.) • `approach` ระยะคนที่ยังเข้าไม่ได้ • `steps` จำนวนก้าวย่ำเท้า •
`hand` / `use` / `x` / `y` มือที่ยกเล็ง (0 ซ้าย, 1 ขวา) และตำแหน่ง • `kp` จุดกระดูก 17 จุด

## ไม่ปิดเอง
* เฟรมไหน error -> ข้ามไป, กล้องไม่ส่งภาพ 4 วินาที -> เปิดกล้องใหม่ (`--stall-s`)
* ยังไม่ได้เสียบกล้อง -> ขึ้นข้อความและรอ ลองใหม่ทุก 3 วินาที
