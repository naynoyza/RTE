# Tracker — กล้อง + YOLO (ตัว/ขา) + MediaPipe (มือ 2 ข้าง) -> Unity

อ่านภาพจากกล้อง Orbbec แล้ว:
* **YOLO11-pose** (ultralytics, รันบนการ์ดจอ NVIDIA ผ่าน CUDA) จับ **ตัว + ขา** ของทุกคน (17 จุด: หัว ไหล่ ศอก ข้อมือ สะโพก เข่า ข้อเท้า) + **ByteTrack** ให้ id คนต่อเนื่อง
* **MediaPipe Hand Landmarker** จับ **มือทั้ง 2 ข้างแบบละเอียด** (21 จุด/มือ, x y z) ของ P1 และ P2 — ตัดภาพเฉพาะรอบแขนของผู้เล่นแต่ละคนก่อน มือจึงได้พิกเซลเยอะแม้ยืนไกล 2–3 ม. และจับคู่กับข้อมือจาก YOLO เพื่อไม่ไปจับมือของอีกคน

ล็อคผู้เล่น 2 คน แล้วส่งข้อมูลให้ Unity ทาง UDP 30 ครั้ง/วินาที

## ติดตั้ง (ครั้งเดียว)
```
setup_venv.bat        (ดับเบิลคลิก: สร้าง venv (Python 3.11) + PyTorch CUDA + pip install -r requirements.txt)
```
ครั้งแรกที่รันจะโหลดโมเดลเองลง `models/`: `yolo11n-pose.pt` (แปลงเป็น `.onnx` ให้อัตโนมัติ เร็วกว่า ~2 เท่า) และ `hand_landmarker.task`

## รัน
1. ดับเบิลคลิก `run_tracker.bat` จะมีหน้าต่างพรีวิวกล้อง
2. Unity: เปิดฉากแล้วกด Play

| ปุ่มในหน้าต่างพรีวิว | ทำอะไร |
|---|---|
| Q / Esc | ปิดโปรแกรม |
| D | คาลิเบรตระยะ: ยืนห่างกล้อง 1 เมตรพอดี แล้วกด (ทำครั้งเดียว) |
| C | คาลิเบรตการเล็ง 6 วินาที: ผู้เล่นกวาดมือที่ยกไปทุกมุม |
| R | ปลดล็อคผู้เล่นทั้งสอง |

ตัวเลือก: `--source 0` (เว็บแคม) • `--model models/yolo11s-pose.pt` (ขาแม่นกว่า แต่ช้ากว่า) • `--no-show`

## ไม่กระตุก
* หน้าต่างพรีวิวกว้าง 960 px เท่าเดิม แต่วาดบนภาพย่อ (เบากว่าวาดบนภาพเต็มแล้วค่อยย่อ)
* กล้องอ่านใน thread แยก เก็บแค่ภาพล่าสุด, ไม่มีการ sleep รอรอบ → ส่งทันทีที่ได้เฟรม (หน่วงน้อยสุด)
* YOLO รันบน GPU ผ่าน ONNX Runtime CUDA (~13 ms/เฟรม บน GTX 1650)
* มือ (MediaPipe, CPU) รันเบื้องหลัง **ไม่รอ**: ตัว/ขา/การเล็งส่งทุกเฟรมของกล้อง, มือใช้ผลล่าสุด (อัปเดต ~18-20 ครั้ง/วินาที)
* ทุกจุด (ตัว/ขา 17 จุด, มือ 21 จุด) ผ่านฟิลเตอร์ One-Euro: อยู่นิ่ง = ไม่สั่น, ขยับเร็ว = ตามทัน
* กรอบตัดภาพมือไม่ขยับตามทุกเฟรม (ขยับเมื่อแขนเลื่อนเกิน 15 %) → MediaPipe ติดตามมือต่อเนื่อง ไม่ต้องหามือใหม่

## กติกาการจับคน
* **เข้าเล่นได้เฉพาะระยะ 2–3 เมตร** (`--min-m 2.0 --join-m 3.0`)
* ยืนฝั่งซ้ายของกล้อง = P1, ฝั่งขวา = P2
* ล็อคแล้วตามคนนั้นจนกว่าจะ **ออกจากกล้อง** คนอื่นในกล้องไม่ถูกนับ
* YOLO หาตัวไม่เจอชั่วครู่ ยังเก็บช่องไว้ `--lost-grace` (1.5 วินาที), ByteTrack จำ id ได้ 2 วินาที (`config/bytetrack_rte.yaml`)

## ข้อมูลที่ส่งให้ Unity (ต่อผู้เล่น)
`present` • `dist` ระยะ (ม.) • `approach` • `steps` ก้าวย่ำเท้า (จากเข่า/ข้อเท้า YOLO) •
`hand` / `use` / `x` / `y` มือที่ยกเล็ง (0 ซ้าย, 1 ขวา) — ใช้กลางฝ่ามือจาก MediaPipe ถ้าเห็น ไม่งั้นใช้ข้อมือ YOLO •
`kp` จุดตัว/ขา 17 จุด (YOLO) •
`handL` / `handR` มือแต่ละข้าง (MediaPipe):
`ok` เห็นไหม, `g` ท่ามือ (`open` `fist` `point` `peace` `pinch` `other`), `f` นิ้วที่เหยียด [โป้ง ชี้ กลาง นาง ก้อย],
`pinch` ระยะโป้ง-ชี้ เทียบฝ่ามือ, `px`/`py` กลางฝ่ามือ, `lm` 21 จุด × [x, y, z]

## ไฟล์
| ไฟล์ | ทำอะไร |
|---|---|
| `tracker.py` | โปรแกรมหลัก: กล้อง → YOLO + MediaPipe → ล็อค P1/P2 → ส่ง Unity |
| `vision.py` | YOLO11-pose + ByteTrack (ตัว + ขา) และ MediaPipe มือ 2 ข้างต่อผู้เล่น (นิ้วที่เหยียด, ท่ามือ) |
| `camera.py` | อ่านกล้อง Orbbec / UVC / ไฟล์วิดีโอ |
| `player_lock.py` | จับคนเข้าช่อง P1/P2 และล็อคจนกว่าจะออกจากกล้อง |
| `gestures.py` | ประมาณระยะ และนับการย่ำเท้า |
| `filters.py` | ฟิลเตอร์ลดอาการสั่นของทุกจุด |

## ไม่ปิดเอง
* กล้องไม่ส่งภาพ 4 วินาที -> เปิดกล้องใหม่, โปรแกรม error -> เริ่มใหม่เองใน 3 วินาที
* ยังไม่ได้เสียบกล้อง -> ขึ้นข้อความและรอ ลองใหม่ทุก 3 วินาที
